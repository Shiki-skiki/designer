# LI SHEN Portfolio

A black-and-red independent designer portfolio, built with HTML, CSS and vanilla JavaScript.

## Preview

Open `index.html`, or run `python -m http.server 8765` and visit `http://localhost:8765`.

## GitHub Pages

Publish from **Settings → Pages → Deploy from a branch → main → / (root)**.

All assets use relative paths, so the site works under a GitHub project URL. `.nojekyll` keeps this a plain static site. No package installation, build command, or API key is required.

## Customize

- `index.html`: page copy and gallery covers.
- `styles.css`: colors, type, layout and responsive styling.
- `script.js`: project details, gallery navigation and motion reel.
- `assets/`: locally hosted images and font.

The five projects are illustrative concepts. Replace their names, dates, descriptions and artwork with your own work before professional use. Replace the example address `hello@lishen.design` in both `index.html` and `script.js`.

The play button opens a 12-second animated image sequence, not a prerecorded video. It supports pause, resume and replay.
